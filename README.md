# Kontrakan Teh Amoy — Web Informasi & Tur 3D Interaktif

**Kontrakan Teh Amoy** adalah aplikasi web interaktif yang dirancang untuk memudahkan calon penyewa melihat ketersediaan unit kontrakan, fasilitas, harga sewa, serta menjelajahi lingkungan dan bagian dalam ruangan secara **3D virtual** langsung dari browser (HP, tablet, maupun komputer).

🌐 **Website Live:** [https://kontrakan-teh-amoy.vercel.app](https://kontrakan-teh-amoy.vercel.app)  
📍 **Lokasi Google Maps:** [Kontrakan Teh Amoy — Pameungpeuk, Jawa Barat](https://maps.app.goo.gl/jueJMjUPuNPdtNwk9)

---

## Tentang Website Ini

Website ini menghadirkan pengalaman survei kontrakan secara online sebelum berkunjung langsung ke lokasi:

- **Visualisasi Lingkungan 3D Realistis:** Menampilkan denah kompleks Kontrakan Teh Amoy sesuai kondisi lapangan — mulai dari Blok Bertingkat (Leter L), Blok 4 Unit Memanjang, Blok 2 Unit Terpisah, Rumah Utama pengelola, gang akses, hingga lingkungan sekitar.
- **Tur Masuk Ruangan 360° (Walk-in 3D):** Pengguna dapat mengklik unit kontrakan untuk membuka pintu dan melihat langsung tata letak bagian dalam (*Ruang Depan*, *Ruang Tengah*, *Lorong Dapur*, dan *Kamar Mandi*) beserta **Mode Denah 3D (Cutaway)**.
- **Informasi Ketersediaan Real-Time:** Menampilkan status setiap unit (*Kosong*, *Terisi*, atau *Perbaikan*), harga sewa bulanan, serta fasilitas seperti **Free WiFi** pada blok tertentu.
- **Privasi Terjaga:** Data penghuni pada tampilan publik disamarkan hanya menampilkan nama depan dan inisial belakang.
- **Responsif di Semua Perangkat:** Dioptimalkan untuk layar **Mobile**, **Tablet**, dan **Desktop** dengan kontrol kamera 3D yang ringan dan mudah digunakan.
